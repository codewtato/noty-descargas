# tu-noty — Descargas

Notas simples que podés compartir con tus amigos.

👉 **[Descargar la última versión](../../releases/latest)**

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `tu-noty_x.y.z_x64-setup.exe` |
| Fedora / openSUSE | `tu-noty-x.y.z-1.x86_64.rpm` |
| Cualquier Linux | `tu-noty_x.y.z_amd64.AppImage` |

### Cómo instalar

- **Windows:** abrí el `.exe`. Si aparece "Windows protegió su PC", tocá **Más información → Ejecutar de todas formas** (pasa porque la app no está firmada, firmarla cuesta plata).
- **Fedora:** `sudo dnf install ./tu-noty-*.rpm`
- **AppImage:** `chmod +x tu-noty_*.AppImage` y abrilo con doble clic.

Este repositorio solo tiene los instaladores; el código es privado.
